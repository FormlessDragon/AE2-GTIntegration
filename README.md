# AE2-GTIntegration

An addon for **Applied Energistics 2 Supergiant** and **GregTech CEu**.

## Features

- **Ignore Integration Circuits in JEI Recipe Transfer**  
  Adds a button to ignore integration circuits when transferring recipes from JEI.

- **Auto-Rename Duplicate Items in JEI Recipe Transfer**  
  Adds a button to automatically rename identical items when transferring recipes from JEI.

- **Circuit Card**  
  Inspired by [NAE2](https://github.com/AE2-UEL/NAE2/blob/2fe8dede709b6917d880f41085cd5ece9042fa7e/src/main/java/co/neeve/nae2/mixin/upgrades/gregcircuit/MixinDualityInterface.java#L52).

- **Extended Encoding Term**  
  Inspired by [Applied Energistics 2 Unofficial](https://github.com/GTNewHorizons/Applied-Energistics-2-Unofficial).  
  Its assets are modified from [Modernity GTNH UI](https://github.com/ModernityGTNH/Modernity-GTNH-UI) and are licensed under [![License: CC BY-NC-SA 3.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%203.0-yellow.svg?style=flat-square)](https://creativecommons.org/licenses/by-nc-sa/3.0/).
